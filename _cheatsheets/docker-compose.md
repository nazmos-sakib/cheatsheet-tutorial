The `docker compose` commands and `compose.yaml` snippets I use most. Run the commands in the folder that holds your `compose.yaml` (or `docker-compose.yml`). Words in CAPS like `SERVICE` or `FILE` are placeholders for your own values. These use Compose v2 (`docker compose`, with a space); on older installs, type `docker-compose` instead.
